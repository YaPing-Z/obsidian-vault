# LLM 协作知识库

这是一个以 Obsidian 为界面、由 LLM 维护 Wiki 的知识库。它不把资料仅作为检索上下文，而是把已读资料逐步沉淀为有来源、有关联、可持续修订的 Markdown 页面。

## 工作方式

1. 把新文件放入 `00 未摄入/`；此处的资料不被改写。
2. 让 LLM 单篇或批量“摄入”资料。它会写入 `10 知识库/`、更新索引和日志。
3. 查询先查 Wiki，必要时回到原始资料核验；有价值的分析继续归档为 Wiki 页面。

## 目录

| 文件夹 | 放什么 |
| --- | --- |
| `00 未摄入` | 不变的原始资料；作为事实来源 |
| `10 知识库` | LLM 维护的 Wiki：主题、实体、来源摘要和分析 |
| `90 Attachments` | 图片、PDF 等附件 |
| `00 Inbox`、`10 Projects`、`20 Notes`、`30 Templates`、`40 Journal` | 既有工作区，暂不自动迁移或删除 |

维护协议见 [[AGENTS]]。建议用 Git 或云盘同步备份整个库。
