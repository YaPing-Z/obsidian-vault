# 使用前先看这个

这是一个已经配置好的 Obsidian 知识库（Vault）骨架，可以直接用。

## 三步开始

1. 把整个 `ObsidianVault` 文件夹复制到你想放的地方（建议 D 盘，或云盘同步目录内）。
2. 打开 Obsidian → 左下角「打开库」图标 → **Open folder as vault** → 选中这个文件夹。
3. 弹窗问是否信任作者时，选**信任并启用插件**（这是你自己复制的本地文件夹）。

已经预置好的设置：

- 粘贴的图片自动进 `90 Attachments`
- 新建笔记默认落在 `00 Inbox`
- 每日笔记自动建在 `40 Journal`，套用日记模板
- 模板目录指向 `30 Templates`

这些在「设置 → 文件与链接 / 核心插件」里可以随时改。

## 目录是这么分的

| 文件夹 | 放什么 |
| --- | --- |
| `00 Inbox` | 还没整理的速记、剪藏、灵感。目标是**定期清空** |
| `10 Projects` | 有明确产出和截止日期的事 |
| `20 Notes` | 整理好的常青笔记，可长期复用 |
| `30 Templates` | 模板 |
| `40 Journal` | 每日笔记，自动按日期命名 |
| `90 Attachments` | 图片、PDF 等附件 |

数字前缀只为了让文件夹按你想要的顺序排列，随时可以改。

## 每天怎么用

1. **收集**：想到什么就按 `Ctrl+N` 新建，或打开今日日记写进去。不用管格式。
2. **连接**：在笔记里输入 `[[`，从弹出的列表里选一篇已有的笔记，链接就建好了。
3. **检索**：`Ctrl+Shift+F` 全局搜索。可以按标签搜 `tag:#速记`、按路径搜 `path:10 Projects`、用 `-某词` 排除。
4. **复用**：写东西时，先搜旧笔记，把相关段落链接过来，而不是重抄一遍。

每周花 10 分钟清空一次 Inbox：能整理成常青笔记的移进 `20 Notes`，没价值的直接删。

## 值得记住的快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+N` | 新建笔记 |
| `Ctrl+O` | 快速切换笔记（模糊搜索） |
| `Ctrl+Shift+F` | 全局搜索 |
| `Ctrl+P` | 命令面板 |
| `Ctrl+G` | 打开关系图谱 |
| `[[` | 插入双链 |
| `Ctrl+E` | 切换阅读 / 编辑模式 |

## 关于 Bases（这个功能值得单独说）

根目录的 `项目看板.base` 是一个数据库视图文件，它把 `10 Projects` 里的笔记显示成表格和看板，用的是每篇笔记顶部的 `status`、`deadline` 属性。

- 打开它，右上角可以切换「表格 / 看板」视图
- 单元格可以**直接点开改**，改的是笔记顶部的属性，不是另存一份数据
- 想新建类似的视图：命令面板搜「数据库：新建数据库」

注意 `.base` 文件是 **YAML 格式**，网上不少教程写成 JSON 是错的。

## 备份（别跳过）

所有内容都是本地 `.md` 文件，没有云端兜底。二选一：

- 把整个库放在 OneDrive / iCloud / 坚果云的同步目录里
- 在库目录执行 `git init`，配合 GitHub 私有仓库每天提交一次

## 下一步可以加什么

先别急，用满一个月再说。真的需要时，按这个顺序装：

1. **Calendar** —— 日历视图，点日期直接跳日记
2. **Templater** —— 比核心模板更强的模板（支持脚本）
3. **Tasks** —— 跨笔记汇总待办
4. **Dataview** —— 复杂查询（现在多数场景 Bases 已经够用）

## 新手最容易犯的错

- 一上来装十几个插件，结果把时间花在折腾工具上
- 文件夹分五六层，最后找不到东西
- 狂收藏不整理，Inbox 永远清不空
- 把关系图谱当整理工具用 —— 它只是好看
