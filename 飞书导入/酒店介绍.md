# 酒店介绍

# 酒店介绍  
  
惠安县印象南洋酒店坐落于惠安县螺阳镇大红埔，临近惠安县体育馆、惠安县县政府、惠安县溪滨公园、东湖公园。周边有禹州城市广场、大润发、宏益百汇，距中心花园步行街仅几分钟车程，溪滨公园、东湖公园是散步、City Walk、跑步、骑行、运动、露营惠安县的最佳场所。风景优美，环湖跑道，有儿童游乐园、游乐设施、摩天轮、跳楼机、海盗船、碰碰车等游乐设施。  
周边小吃丰富，娱乐设施多种多样。繁华商圈。
